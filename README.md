# 小红书多账号采集工作台

这是一个专注小红书营销开发的辅助工具，也是原“小红书公开数据采集工作台”的 2.0 多账号桌面版。左侧仍是可操作的真实小红书页面，右侧保留搜索笔记、作者笔记、笔记评论和自动化操作区。新版的每个账号都拥有独立持久化浏览器会话，可以同时保持登录并随时切换。

## 多账号如何工作

- 首次启动会创建一个默认账号容器。
- 在顶部账号栏点击“添加账号”，会创建新的独立会话并打开小红书首页。
- 在对应的嵌入页面中由你本人完成扫码、手机号、验证码或风控验证。应用不会绕过这些流程。
- 切换账号只会改变当前可见的嵌入页面；其他账号的 Cookie、本地存储、当前页面、采集状态和登录态仍然保留。
- 笔记、评论、作者任务、评论队列和笔记操作队列都按账号隔离，不会因切换页面而串到另一个账号。
- 移除账号需要二次确认，并且只清理该账号的本地会话和工作区数据。

## 真实采集与操作

1. 切换到要使用的账号，确认顶部状态显示“已登录”。
2. “采集搜索笔记”：输入关键词和目标数量，点击“采集笔记”。
3. “采集作者笔记”：粘贴小红书作者主页地址，点击“开始”。
4. “采集笔记评论”：粘贴保留了 `xsec_token` 及来源参数的完整笔记地址，点击“采集”。
5. 搜索和作者结果行的右键菜单可以把当前或已勾选笔记加入评论采集队列或笔记操作队列。
6. 自动化操作依旧按分钟设置间隔，每次间隔会在设定值上下 10 秒内随机浮动，并以两位小数显示。评论发送前会在正文内部随机插入一个 `.` 和一个 emoji，任务表保留中文阶段和耗时。

应用只整理真实嵌入页面已经收到的公开响应，不伪造签名、不导出 Cookie，也不会把 localhost 预览或演示数据标为成功采集。

## 开发与验证

需要 Node.js 22.12 或更高版本。首次运行先安装依赖：

```bash
npm install
```

随后执行完整检查或启动桌面版：

```bash
npm run check
npm run desktop
```

`npm run dev` 启动的本地页面只用于检查布局和交互，浏览器安全边界决定了它不能验证小红书多账号登录隔离。完整验收需在 Electron 桌面窗口中创建至少两个账号，分别登录、切换，并在重启应用后再次确认两个会话仍然独立保留。

## 使用边界

- 只采集你有权访问和使用的数据，并遵守平台协议、隐私规则和适用法律。
- 不要用于建立个人画像、骚扰用户、出售用户资料或未经授权的批量营销。
- 应用不处理验证码、不绕过风控、不伪造请求签名，也不导出、复制或共享任何账号的 Cookie。
